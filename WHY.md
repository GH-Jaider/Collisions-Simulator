# Why this exists

I wrote the first version of this for a mechanical physics course. It did the job at the time and then sat where I left it for a long while.

I came back to it by accident. I was learning up on these basic physics to work out how something in a game behaved, and I kept wanting somewhere to poke at collisions directly instead of only reading about them. The old project was already sitting there, so I picked it up and polished it into something I would actually want to open.

That is the whole story. A little physics sandbox
